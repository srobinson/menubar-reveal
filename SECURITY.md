# Security Policy

## Supported versions

Only the latest release of Menu Bar Reveal receives security fixes.
The current latest release is listed on the
[Releases page](https://github.com/srobinson/menubar-reveal/releases/latest).
Please update to it before reporting an issue.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub private vulnerability
reporting on this repository's Security tab:
https://github.com/srobinson/menubar-reveal/security/advisories/new

Please do not open a public issue for a security vulnerability.

## What to include

- Menu Bar Reveal version (shown in the app or in the release you installed)
- macOS version
- Steps to reproduce the issue
- What you expected to happen and what happened instead
